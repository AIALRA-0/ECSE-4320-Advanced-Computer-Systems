## 5 兼容性修正

当前 Windows 工作副本把 17 个 Shell 与 Bash 脚本检出为 CRLF 行尾，直接交给 WSL Bash 后会解析失败，本次验证前统一为 LF 行尾，没有改变命令语义

新增 `.gitattributes`，使 Git 在不同操作系统的工作副本中都把 Shell 脚本检出为 LF 行尾

新增 `.gitignore`，阻止后续提交虚拟环境、缓存、本地构建目录和本地配置

`.gitignore` 不会自动移除已经跟踪的 8,399 个虚拟环境文件，后续清理需要单独审核依赖锁定、历史保留和仓库体积变化
